# Linear Algebra for Data Science and Machine Learning: Companion Notebooks

Companion Jupyter notebooks for *Linear Algebra for Data Science and Machine Learning: Worked Examples and Python* by Dr. Sajjad Shaukat Jamal (Skills Outlet).

Each notebook contains every Python example from one chapter, in the order it appears in the book. Work each example by hand first, then run the cell to check your result. Cells within a chapter build on each other, so run them from top to bottom.

| Notebook | Chapter |
|---|---|
| Chapter_01_vectors_and_a_simple_prediction.ipynb | 1. Vectors and a simple prediction |
| Chapter_02_vector_operations_and_geometry.ipynb | 2. Vector operations and geometry |
| Chapter_03_matrices_as_datasets_and_transformations.ipynb | 3. Matrices as datasets and transformations |
| Chapter_04_matrix_multiplication.ipynb | 4. Matrix multiplication |
| Chapter_05_solving_linear_systems.ipynb | 5. Solving linear systems |
| Chapter_06_span_independence_basis_and_rank.ipynb | 6. Span, independence, basis, and rank |
| Chapter_07_orthogonality_and_projections.ipynb | 7. Orthogonality and projections |
| Chapter_08_least_squares_and_linear_regression.ipynb | 8. Least squares and linear regression |
| Chapter_09_eigenvalues_and_eigenvectors.ipynb | 9. Eigenvalues and eigenvectors |
| Chapter_10_singular_value_decomposition.ipynb | 10. Singular value decomposition |
| Chapter_11_principal_component_analysis.ipynb | 11. Principal component analysis |
| Chapter_12_gradients_jacobians_and_matrix_calculus.ipynb | 12. Gradients, Jacobians, and matrix calculus |
| Chapter_13_an_integrated_prediction_project.ipynb | 13. An integrated prediction project |

## Running the notebooks

```bash
pip install -r requirements.txt
jupyter lab
```

The notebooks also run in Google Colab: upload a notebook, or open it from GitHub once this folder is published there.

All datasets, prices, and model weights are invented for instruction.
